노링 개인정보처리방침

시행일 2026년 10월 31일

노링(https://noriya1302.github.io/norivoka/)는 영어 단어 복습 웹앱이에요. 이 방침은 노링이 어떤 정보를 왜 모으고, 어떻게 지우는지 설명해요.

1. 모으는 정보

  • 계정 정보: 아이디로 가입하면 아이디와 비밀번호(암호화되어 Google Firebase에 저장), 구글·페이스북·카카오로 로그인하면 해당 서비스가 주는 이름과 이메일, 휴대폰 번호로 로그인하면 휴대폰 번호
  • 학습 기록: 단어별 정답·오답 기록, 복습 일정, 설정, 닉네임
  • 순위표 정보: 닉네임, 이번 주 학습한 단어 수, 연속 학습 일수, 마지막 학습일 (설정에서 순위표 참여를 끄면 모으지 않아요)
  • 알림 정보: 알림을 켠 기기의 푸시 알림 주소

2. 쓰는 목적

  • 로그인과 여러 기기 사이의 학습 기록 동기화
  • 복습 일정 계산, 연속 기록, 분석 화면
  • 친구들끼리 보는 순위표
  • 매일 아침 학습 알림

광고나 판매 목적으로 쓰지 않고, 다른 곳에 팔거나 넘기지 않아요.

3. 다른 사람에게 보이는 정보

순위표에 참여한 경우 닉네임, 이번 주 단어 수, 연속 일수만 다른 사용자에게 보여요. 단어별 학습 기록과 오답은 본인만 볼 수 있어요.

4. 저장 위치와 맡기는 곳

  • Google Firebase (로그인, 데이터 저장, 휴대폰 문자 인증)
  • Meta(Facebook), 카카오, Google (선택한 소셜 로그인)
  • GitHub (웹앱 호스팅, 알림 발송 실행)

5. 보관 기간

계정을 지울 때까지 보관해요. 계정을 지우면 학습 기록, 순위표 정보, 알림 정보를 함께 지워요.

6. 정보 삭제 방법

  • 학습 기록만 지우기: 앱의 설정 → 기록 초기화
  • 순위표에서 빠지기: 설정 → 순위표 참여 끄기
  • 알림 정보 지우기: 설정 → 알림 끄기
  • 계정과 모든 정보 삭제: 아래 문의처로 노링 닉네임과 로그인 방법을 적어 요청하면 7일 안에 지워요. 페이스북으로 로그인했다면 페이스북 설정 → 앱 및 웹사이트에서 노링을 삭제한 뒤 요청해 주세요.
